# jiexin-desktop-release

染厂染料管理系统（桌面版）官方更新分发仓库。

本仓库仅包含版本更新清单（releases/latest.json）与安装程序附件，不含任何源代码。
客户端内置更新器从本仓库自动检测新版本并下载安装包（支持 Gitee / GitHub 双线路自动切换）。

安全提示：请仅从本仓库或官方渠道获取安装包，安装包与激活授权一一绑定。
